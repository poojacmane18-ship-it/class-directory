# Class Directory

Welcome to our class directory.

Each student adds **one profile page** to the folder named `profiles`.

## How to add your page

1. Make a copy of this repository (this is called a **fork**).
2. Open the `profiles` folder.
3. Create a new file called `yourname.md`.
4. Copy the text from `TEMPLATE.md` and fill it in.
5. Propose your change (this is called a **pull request**).

## Rule

- Use only your first name and your college or field.
- Do not share your phone number or home address.
- Be kind in every comment.
